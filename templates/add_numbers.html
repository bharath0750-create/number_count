Input Format Guide

Enter numbers in any of these formats:

  • One per line: 1234 / 5678 / 123
  • Comma-separated: 1234, 5678, 123
  • Space-separated: 1234 5678 123
  • Mixed: 1234, 5678 123\n456
Classification Rules: Exactly 3 digits = 3D | Exactly 4 digits = 4D | Anything else = Invalid
Duplicates: All entries are counted individually. Repeated numbers create separate records.
Scan Numbers from Photo

For better accuracy, use a clear, well-lit photo with straight numbers and minimal background noise.
